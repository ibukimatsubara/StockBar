2. コア機能

2.1 表示内容

  • 銘柄名（or 銘柄コード）
  • 現在値
  • 前日終値比（円 + %）
  • 騰落の色分け：プラス=赤 / マイナス=緑

2.2 ローテーション

  • 複数銘柄を一定間隔で順に切り替え
  • 順序はユーザー指定（管理画面でドラッグ並び替え）
  • 切替間隔は設定可（3 / 5 / 10秒など）

2.3 自動更新

  • 市場時間中のみ取得（東証 9:00–11:30 / 12:30–15:00 JST）
  • 市場閉場中は最後の値を表示、更新停止
  • 更新間隔は設定可（デフォルト 1 分）

3. 銘柄管理 UI

メニューバーアイコンをクリックでポップオーバーが開く。

機能挙動
追加銘柄コード入力 → API で名称取得 → 確認後に登録
削除各行の ✕ ボタン
並び替えドラッグハンドルで上下入れ替え（=表示順）
個別非表示トグルでローテーションから一時的に除外
集中モード1クリックで全銘柄を一括非表示（会議・画面共有用）
設定切替速度、更新間隔、表示フォーマット

4. データソース

当面は query1.finance.yahoo.com（Yahoo Finance 非公式）を採用。銘柄コードは Yahoo 形式：

  • 日本株：7203.T（トヨタ）
  • 指数：^N225（日経平均）
  • 米国株：AAPL

将来的に Alpha Vantage / Finnhub への切替も視野。

5. 技術スタック

  • Swift + SwiftUI
  • MenuBarExtra（macOS 13+）
  • URLSession + async/await
  • 永続化：UserDefaults or JSON ファイル

6. 開発フェーズ

  1. 1銘柄固定で取得 → メニューバー表示する最小実装
  2. 複数銘柄 + ローテーション
  3. 銘柄管理ポップオーバー（追加/削除/並び替え/個別非表示）
  4. 設定（速度・更新間隔）+ 集中モード
  5. 市場時間判定・永続化・仕上げ
